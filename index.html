Setiap strategi memiliki trade-off antara kompleksitas implementasi dan efisiensi memori.

FIFO
First In, First Out

Halaman yang paling lama berada di memori akan diganti pertama. Menggunakan struktur antrian (queue). Rentan terhadap anomali Bélády.

Struktur data:
Queue FIFO → [P1, P2, P3 ...] → dequeue P1 (terlama)
Queue O(1) Anomali Bélády ⚠
LRU
Least Recently Used

Mengganti halaman yang paling lama tidak diakses. Memanfaatkan prinsip lokalitas temporal. Tidak mengalami anomali Bélády.

Stack
Implementasi
O(n)
Kompleksitas
✓
No Anomali
OPT
Optimal (Bélády's Algorithm)

Mengganti halaman yang paling lama tidak akan digunakan di masa depan. Page fault minimum secara teori — tidak dapat diimplementasikan di sistem nyata. Digunakan sebagai benchmark perbandingan.

CLOCK
Clock (Second Chance)

Aproksimasi LRU menggunakan reference bit. Pointer berputar seperti jarum jam.

Bit = 1 → beri second chance (set ke 0, lewati)
Bit = 0 → ganti halaman ini
